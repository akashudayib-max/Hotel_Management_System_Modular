HOTEL MANAGEMENT SYSTEM - MODULAR PYTHON PROJECT

FILES
-----
main.py      : Starts the program and displays the main menu.
admin.py     : Admin login, add room, remove room and view rooms.
customer.py  : Customer signup, login, room search, booking and cancellation.
room.py      : Room class and room details.
hotel.py     : Hotel data and room display operations.
storage.py   : Reads and writes JSON data files.
data/        : Stores rooms.json, customers.json and bookings.json.

HOW TO RUN
----------
1. Keep all .py files in the same project folder.
2. Open this folder in VS Code or another Python editor.
3. Run main.py.
4. Do not run admin.py or customer.py directly.
